On my machine it is using around 100 MB or RAM and around 0.1% of CPU.

To build and run an app everything you need is 

```
git clone https://github.com/Mnichus3142/aetherd
cd aetherd
npm start
```

After that you can ```npm start``` or ```node /dist/index.js``` to run the app.
